Android Activity patch for permission callback

Goal
- Provide a simple Java/Kotlin helper `PermissionBridge` and example `onRequestPermissionsResult` code for the Android Activity produced by Briefcase/Toga.
- The helper stores the last `grantResults` in a static field that Python (via pyjnius) can poll quickly. This avoids complex JNI plumbing.

Files to add in the Android project (e.g., app/src/main/java/org/example/alarma/):

1) PermissionBridge.java

```java
package org.example.alarma;

public class PermissionBridge {
    private static int[] lastGrantResults = null;

    public static void setLastGrantResults(int[] results) {
        lastGrantResults = results;
    }

    public static int[] getLastGrantResults() {
        return lastGrantResults;
    }
}
```

2) In your Activity (the one generated by Briefcase/Toga) add/modify `onRequestPermissionsResult` to set the bridge:

Java example:

```java
@Override
public void onRequestPermissionsResult(int requestCode, String[] permissions, int[] grantResults) {
    super.onRequestPermissionsResult(requestCode, permissions, grantResults);
    // notify bridge for Python side
    org.example.alarma.PermissionBridge.setLastGrantResults(grantResults);
}
```

Kotlin example:

```kotlin
override fun onRequestPermissionsResult(requestCode: Int, permissions: Array<String>, grantResults: IntArray) {
    super.onRequestPermissionsResult(requestCode, permissions, grantResults)
    org.example.alarma.PermissionBridge.setLastGrantResults(grantResults)
}
```

How Python uses it
- `Controlador/calendar_adapters/android_adapter.py` already polls `PermissionBridge.getLastGrantResults()` for up to 15s after requesting permissions. If present, Python interprets the results and proceeds accordingly.

Notes
- This approach avoids direct Java->Python calls but gives the Activity a simple static bridge to expose results.
- For production, prefer a direct callback integration or proper event dispatch from Activity into Python runtime.

Applying the patch
- Add `PermissionBridge.java` under `app/src/main/java/org/example/alarma/` (or appropriate package path created by Briefcase).
- Rebuild the Android project and deploy.
